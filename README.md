# Manufacturas Bell

Web estática con catálogo sin precios, fichas compartibles, bolsa de productos, modos claro/oscuro y consultas por WhatsApp.

## Cloudflare Pages

Conectar este repositorio, rama `main`. Framework: None. Sin comando de compilación. Directorio de salida: `dist`.

Los archivos públicos y todas las imágenes y el video están dentro de `dist`. No requiere variables secretas ni dependencias.

## Prueba local

Ejecutar `node servidor-local.cjs` o `ABRIR-EN-WINDOWS.bat`. Consultar `COMO-ABRIR.txt` para acceso desde el celular.
